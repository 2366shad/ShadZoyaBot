SHAD ZOYA - Android Studio project

IMPORTANT:
- Yeh starter project hai, ready-made APK nahi.
- APK banane ke liye Android Studio mein is folder ko Open karein aur Gradle Sync ke baad Build > Build APK(s) karein.
- Android Studio / Android SDK aur internet pehli build ke liye zaroori hain.
- App Messenger ke screen par accessibility se jo text expose hota hai, usse funny reply suggest karta hai. Messenger har message/reaction ko accessibility mein expose nahi karta; isliye har message pakadne ki guarantee nahi hai.
- App koi message khud send nahi karta. Reply ko check karke Copy karein aur Messenger mein paste karein.
- Floating button ke liye "Display over other apps" permission aur message reading ke liye Accessibility permission user ko Android Settings mein khud enable karni hogi.
- Accessibility permission sensitive hoti hai: ise sirf apne phone par, samajhkar enable karein. Captured text app ke local preferences mein rehta hai; koi server upload code nahi hai.
- Package: com.mastiking.bot
- Minimum Android: 8.0 (API 26)
